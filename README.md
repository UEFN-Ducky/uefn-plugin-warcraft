# Warcraft

Fantasy RTS war-room — carved gold frames, parchment panels, gem radios, scroll toasts, faction cursors. Powered by warcraftcn-ui (MIT).

Desktop plugin for [UEFN-Ducky](https://github.com/UEFN-Ducky/UEFN-Ducky) (`warcraft`).
Install or update from **Settings → Store** in the app — do not install from a zip by hand.

## Build

```bash
py scripts/build_zip.py
```

Writes `deploy/warcraft-1.0.9.ducky-plugin.zip` (scripts/ and deploy/ are not packed).
